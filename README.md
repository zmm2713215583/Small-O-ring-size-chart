# Small O-Ring Size Chart Dataset

This repository provides a clean, machine-readable dataset (`.csv`) of small-diameter O-ring dimensions in both Imperial (inch) and Metric (mm) units for mechanical engineers, medical device designers, and precision fluid power specialists.

## Technical Specifications
* **Standard Ranges**: Micro O-rings, miniature AS568 O-rings, and custom metric cross-sections.
* **Material References**: NBR, FKM, EPDM, Silicone, and FFKM compounds.
